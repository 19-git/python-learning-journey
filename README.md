# Python Learning Journey

系统学习 Python 的过程记录，从基础语法到高级特性、数据结构与并发编程。
保留了学习过程中的原始代码与注释，是一份可追溯的学习日志，而非整理后的标准答案。

## 目录结构

| 目录 | 内容 |
|---|---|
| `closures_and_decorators/` | 闭包与装饰器 |
| `generators_and_regex/` | 生成器与正则表达式 |
| `linked_list_impl/` | 手写链表实现 |
| `binary_tree_impl/` | 手写二叉树实现 |
| `sorting_algorithms/` | 常见排序算法实现 |
| `concurrency_and_networking/` | 多线程与网络编程 |
| `pagination_show/` | 数据分页（翻页）示例与学习日志 |
| `flask_learning/`  | Flask Web 入门（服务器/路由/表单提交）与学习日志 |

## 环境

- Python 3.11
- 每个文件夹可独立运行；flask_learning 需先安装 Flask（`pip install flask`）

## 说明

这个仓库记录了我从零开始系统学习 Python 的过程：
- 每个文件夹对应一个专题，里面是当时的练习代码与个人注释
- 代码风格保留了学习阶段的原始状态，用于复盘和展示思考过程
- 后续会持续补充新的专题
