# 学习日志：Flask Web 入门（2026-10-31）

## 学习背景

为了让学生管理系统（StudentCMS）能够部署上线、拿到"线上可访问链接"，必须有 Web 界面。
因此在 Python 学习之旅中新增了 flask_learning 文件夹，开始学习 Flask，了解制作网页界面的过程，为后续改造系统做准备。

## 学习目标

掌握制作 Web 界面的三个核心环节：

1. 浏览器和程序之间怎么通信（服务器 + 路由）
2. 网址怎么区分不同功能（路由参数）
3. 网页输入怎么进入程序（表单 + POST）

## 学到的内容

### 1. 服务器 + 路由（app1.py）

- `Flask(__name__)`：创建一个 Flask 应用，相当于搭好服务器的架子
- `@app.route("/")`：装饰器，把"网址"和"函数"绑定——访问首页就执行下面的函数
- `app.run()`：启动服务器，程序从此一直监听，浏览器访问 http://127.0.0.1:5000 就能看到页面

### 2. 网址参数（app2.py）

- `@app.route("/user/<name>")`：`<name>` 是网址参数（Flask 固定写法）
- 访问 `/user/张三`，函数里的 `name` 就自动变成 `"张三"`，同一个函数返回不同内容

### 3. 表单提交（app3.py）

- `<form method="post" action="/hello">`：表单区域，提交方式用 POST，数据发往 `/hello`
- `<input name="name">`：输入框，`name="name"` 是取值的钥匙
- `request.form["name"]`：函数里用这行拿到用户填的内容

## 控制台版 vs Web 版（对应关系）

| 控制台版（已有系统） | Web 版（Flask） |
|---|---|
| 菜单编号（input 选择） | 路由网址 `@app.route` |
| `input()` 接收输入 | `<form>` + `<input>` + `request.form[...]` |
| `print()` 显示结果 | `return` 页面内容 |

## 验证

- app1：浏览器打开 127.0.0.1:5000，看到首页文字
- app2：访问 /user/张三，页面显示"你好，张三！…"
- app3：首页输入名字点提交，页面显示"我收到了你提交的内容"

## 总结

Web 界面不是重新写一个系统，而是把"黑框输入输出"换成"网页表单和页面显示"，业务逻辑可以原样复用。
搞懂上面三个对应关系，改造学生管理系统就有了钥匙。
