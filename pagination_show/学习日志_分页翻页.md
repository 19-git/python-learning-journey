# 学习日志：数据分页（翻页）

**日期：** 2026-10-25
**专题：** 数据分页（每页 10 条，输入页码翻页）

---

## 学习目标

实现"学生多了只显示 10 条，输入页码翻页"的分页效果，理解分页的核心公式，为以后后端分页接口打基础。

## 核心知识点（3 个公式/结构）

1. **切片取一页**：`list[start:end]`——第 n 页 = `list[(n-1)*page_size : n*page_size]`
2. **总页数（向上取整）**：`pages = (total + page_size - 1) // page_size`——25 条 ÷ 10 = 2 余 5，余下的 5 条也得占一页，所以是 3 页
3. **翻页循环**：`while True` + 页码校验（`isdigit` + 范围判断）+ `q` 退出

## 遇到的问题

**第一页显示正常（学生1~10），输入页码翻页后，页面变空白，一个学生都看不到。**

## 原因分析

变量名遮蔽（变量覆盖）：

- 第 2 行：列表变量叫 `student`
- 第 16 行：`for` 循环变量也叫 `student`
- Python 的 `for` 循环会把**每个元素轮流赋给循环变量** `student`，第一页循环结束后，`student` 从"列表"变成了"学生10"（字符串）——**列表被覆盖没了**
- 翻页时 `student[start:end]` 变成对字符串"学生10"做切片，结果是空 → 页面空白

## 解决

给循环变量换一个名字，和列表区分开：

```python
for stu in student[start:end]:
    print(" ", stu)
```

## 学到的一课（重点）

**循环变量永远不要和容器变量重名！**

`for` 循环会把元素覆盖到循环变量上，一旦同名，循环结束后容器变量就变成了最后一个元素，数据被"吃掉"。这是 Python 初学者很容易踩的经典坑，面试也可能考"变量遮蔽"。

## 验证

修改后重新运行：

- 输入 `2` → 显示学生11~20 ✅
- 输入 `3` → 显示学生21~25 ✅
- 输入 `0` / `99` → 提示"页码无效" ✅
- 输入 `q` → 返回 ✅
